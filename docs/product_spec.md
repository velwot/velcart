# PureScan Product Specification

## Goal

Build an Android-first Flutter application that can:

Barcode → product lookup → ingredients → ingredient analysis → PureScan Analysis Score → explanation → history.

## V1 Features

- Home
- Barcode scanning
- Manual barcode entry
- Product lookup
- Ingredient normalization
- Local ingredient database
- Deterministic score
- Ingredient analysis
- Scan history
- Search
- Basic settings

## Later Features

- Ingredient-label OCR
- User-reviewed OCR text
- Optional Gemini explanations
- Offline caching improvements
- Product comparison
- More comprehensive product/ingredient coverage
