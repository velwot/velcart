# Agent Workflow

For each milestone:

1. Read `AGENTS.md`.
2. Read the relevant skill.
3. Read affected documentation.
4. Inspect current implementation.
5. Implement only the requested milestone.
6. Run formatter.
7. Run `flutter analyze`.
8. Run `flutter test`.
9. Run Android build when applicable.
10. Fix failures.
11. Summarize changed files and verification.
12. Create a Git checkpoint after a successful milestone.

Recommended checkpoints:

- milestone-0-foundation
- milestone-1-scanner
- milestone-2-product-api
- milestone-3-ingredients
- milestone-4-scoring
- milestone-5-analysis-ui
- milestone-6-ocr
- milestone-7-gemini
- milestone-8-history
- milestone-9-search
- milestone-10-release
