# Gemini Skill

Gemini is an explanation layer, not the scoring engine.

Allowed:
- simplify supplied evidence
- explain ingredient information
- summarize structured analysis
- explain uncertainty

Not allowed:
- invent studies or sources
- diagnose medical conditions
- change the numerical score
- turn unknown information into a harmful classification

Require explicit user action before an AI explanation request.
Never hard-code production API secrets into the app.
